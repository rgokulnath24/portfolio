# Gokulnath — Developer Portfolio

A modern, responsive developer portfolio built with **Next.js, TypeScript, and Tailwind CSS**. The portfolio is designed to showcase my professional experience, technical skills, selected projects, and provide an easy way to get in touch.

## ✨ Overview

This portfolio focuses on a clean, premium developer experience with:

* Dark-first modern UI
* Responsive design across devices
* Component-based architecture
* Data-driven sections
* Smooth interactions and subtle animations
* Project showcase
* Professional experience timeline
* Skills and technology overview
* Contact and social links

## 🚀 Tech Stack

## 🎨 Design

The portfolio uses a dark developer-focused visual system with:

* Deep charcoal backgrounds
* Subtle borders
* Violet primary accent
* Cyan secondary accent
* High-contrast typography
* Rounded cards
* Glassmorphism elements
* Responsive layouts
* Minimal visual effects

The goal is to keep the interface **professional, readable, and developer-oriented** rather than overly decorative.
